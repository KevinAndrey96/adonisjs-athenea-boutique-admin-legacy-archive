## 📌 Historical Overview

This repository preserves the historical administrative backoffice component originally developed for the Athenea Women Fashion Boutique Platform. It featured catalog categorization, order tracking, and discount coupon controls.

All components, database schemas, and workflows have been merged and modernized into the primary repository: **[fashion-boutique-ecommerce-platform](https://github.com/KevinAndrey96/fashion-boutique-ecommerce-platform)**.
